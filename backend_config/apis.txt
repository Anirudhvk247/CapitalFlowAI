API CONFIGURATION

General Rules

- Read the Twelve Data API key from ".env" using "TWELVE_DATA_API_KEY".
- Read the Upstox bearer token from ".env" using "UPSTOX_BEARER_TOKEN".
- Never hardcode secrets.
- Call each endpoint exactly once during every scheduled run.
- Store market data into Table 1 ("market_data").
- Store institutional flow data into Table 4 ("fii_dii_flow").

For EVERY Twelve Data response

Example response:

{
    symbol,
    name,
    exchange,
    mic_code,
    datetime,
    timestamp,
    datetime_gmt,
    open,
    high,
    low,
    close,
    previous_close,
    change,
    percent_change,
    is_market_open
}

Store ONLY these fields into Table 1 ("market_data"):

- "date = datetime"
- "index_name = name"
- "price = close"
- "percent_change = percent_change"
- "status ="
  - ""OPEN"" if "is_market_open == true"
  - ""CLOSED"" if "is_market_open == false"

Ignore:

- symbol
- exchange
- mic_code
- timestamp
- datetime_gmt
- open
- high
- low
- previous_close
- change

FII API

Endpoint

https://api.upstox.com/v2/market/fii?data_type=NSE_EQ%7CCASH&interval=1D

Headers

Accept: application/json

Authorization:
Bearer ${UPSTOX_BEARER_TOKEN}

Example response

{
    status,
    data:[
        {
            date,
            data_type,
            buy_value,
            sell_value,
            net_value
        }
    ]
}

Store ONLY:

- "date = data[0].date"
- "fii_netflow = data[0].net_value"

Ignore:

- status
- data_type
- buy_value
- sell_value

Upstox API Request Instructions

For all FII and DII API calls:

- Do NOT append the bearer token to the URL.
- Read the bearer token from ".env" using:

"UPSTOX_BEARER_TOKEN"

The request must be sent using HTTP headers.

Example:

import requests

url = "https://api.upstox.com/v2/market/dii?data_type=NSE_EQ%7CCASH&interval=1D"

headers = {
    "Accept": "application/json",
    "Authorization": f"Bearer {UPSTOX_BEARER_TOKEN}"
}

response = requests.get(url, headers=headers)

Similarly, for the FII endpoint:

import requests

url = "https://api.upstox.com/v2/market/fii?data_type=NSE_EQ%7CCASH&interval=1D"

headers = {
    "Accept": "application/json",
    "Authorization": f"Bearer {UPSTOX_BEARER_TOKEN}"
}

response = requests.get(url, headers=headers)

Rules:

- Always read the bearer token from ".env".
- Never hardcode the bearer token.
- Never place the bearer token inside the URL.
- Always send it using the "Authorization" header in the format:

"Authorization: Bearer <UPSTOX_BEARER_TOKEN>"

- Parse the JSON response and extract only the required fields for Table 4 ("fii_dii_flow"):
  - "date"
  - "fii_netflow"
  - "dii_netflow"
  - "total_netflow = fii_netflow + dii_netflow"



Do not store any additional fields.
